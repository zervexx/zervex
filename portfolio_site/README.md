# Portfolio — G.

Статический портфолио-сайт с тремя проектами:
- БРОДЯГА — барбершоп
- NOIR — ресторан
- EIRN — fashion e-commerce

## Запуск локально
Откройте `index.html` в браузере или запустите любой static server.

## Публикация
Папку можно загрузить в GitHub Pages, Vercel или Netlify.
Перед публикацией замените ссылку `https://t.me/` в `index.html` на свой Telegram.
